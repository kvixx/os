Запуск cargo run 
Установка
1. Скачайте и запустите установщик:bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
Используйте код с осторожностью.
2. Выберите стандартный вариант установки (нажмите 1 и Enter).
3. Примените изменения переменных окружения в текущей сессии терминала:bash
source "$HOME/.cargo/env"
